MODIFICATIONS AND REPRODUCTION METHOD

Modified by cruush: select is_territorial = true and subtype locality or
localadmin from all eight pinned division_area source objects. Preserve the
source area/division IDs, names, country/region codes and complete 2D WKB
Polygon/MultiPolygon geometry. Compress geometry losslessly using zlib level
6; index exact geometry extents with SQLite R-tree outward rounding. No
boundary simplification, nearest-city substitution or invented hierarchy.

The recorded build contains 576,368 records across 229 source country codes.
This is complete extraction of the stated filter, not a guarantee of every
real-world town or legal municipal boundary. Unknown or ambiguous locations
must not invent a town label.

The complete alteration method and supporting files are provided at:
/town-boundaries/2026-09-23.1/REPRODUCE.md
/town-boundaries/2026-09-23.1/extract.py
/town-boundaries/2026-09-23.1/build_dataset.py
/town-boundaries/2026-09-23.1/source-manifest.json
/town-boundaries/2026-09-23.1/schema.sql
/town-boundaries/2026-09-23.1/towns.sqlite.manifest.json

REPRODUCE.md includes dependency versions, setup and rebuild commands,
resource limits and conservative lookup requirements. The matching release
manifest includes all source object URLs/checksums, script hashes, recorded
build versions, output hash and validation counts. Byte-identical output
across different library versions is not promised. The database and its
alterations are offered under ODbL 1.0; retain the contributor notices above.

Database and reproduction files

The cruush derivative database is not published for download here. The complete transformation method, source files and matching release manifest are provided below so the derivative can be rebuilt from the pinned public source data.

The derivative selects territorial locality and localadmin areas, preserves source names, country/region codes and full 2D boundary geometry, compresses geometry losslessly with zlib and adds a SQLite R-tree index. Boundaries are not simplified. The release includes 576,368 records across 229 source country codes; this is not a guarantee of coverage for every real-world town. No member locations, saved member states or account data are included.

# cruush is an application, not a content site. Only the landing page is
# indexable; every authenticated surface stays out of every index.
#
# Crawling is allowed where indexing is denied on purpose. A crawler blocked
# here never fetches the page, so it never sees the X-Robots-Tag that removes
# it, and a blocked-but-linked URL can still surface as a bare result. Serving
# noindex to a crawler that is allowed to fetch is what actually removes a URL.
#
# None of this is a privacy control. Member data is behind authentication and
# is unreachable without a session.

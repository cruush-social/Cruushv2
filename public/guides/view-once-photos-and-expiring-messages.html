View-once photos and expiring messages

Written by Julien Lenaz, lead developer of cruush. October 6, 2026

View once

A photo sent in a message can be set to view once, so it does not stay in the chat.

Expiring messages

Messages can be set to expire so they do not sit in a conversation indefinitely.

The limit

Anyone can screenshot or photograph a screen. These options limit how long something stays in a chat. They do not guarantee no copy exists, so send only what you can live with.

When to use them

Use view once for photos you only want someone to see in the moment. Use expiring messages for conversations you do not want to sit around, such as details about where you are meeting.

If someone does not respect it

Block them from their profile. It takes effect immediately. Report them too, because a person reads every report.
